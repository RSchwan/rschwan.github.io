# Academic Profile

Static personal academic page for GitHub Pages.

## Development

Install dependencies:

```sh
npm install
```

Build the publications section and Tailwind stylesheet:

```sh
npm run build
```

Regenerate only the publications section after editing `data/publications.bib`:

```sh
npm run pubs
```

During editing, run:

```sh
npm run dev
```

Configure GitHub Pages to publish from the `docs/` folder on the main branch.
